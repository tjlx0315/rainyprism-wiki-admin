# 雨棱镜｜世界观百科后台

一个用于整理原创角色（OC）世界观资料的本地编辑器。目前使用原生 HTML、CSS 和 JavaScript 开发，数据保存在浏览器的 `localStorage` 中。

## 当前功能

- 角色、势力、地区、事件及其他类型卡片
- 按卡片类型提供不同的可添加模块
- 卡片关系与总关系网
- 卡片时间轴与全局时间轴
- 代表图和图片资料
- 模块添加、编辑、复制、折叠、排序、删除与撤销
- 全部数据 JSON 导入与导出
- 本地浏览器数据持久化

## 本地使用

直接用浏览器打开 `index.html` 即可使用。

也可以在项目目录启动任意静态文件服务器，然后访问对应的本地地址。

## 数据说明

当前数据仅保存在打开页面的浏览器中，不会自动上传到网络，也不会写入 Git 仓库。

建议定期使用页面中的“导出备份”功能保存 JSON 文件。导入备份会覆盖当前浏览器中的世界观数据，操作前请确认文件正确。

项目目前尚未连接云端数据库。未来可以在保持现有编辑功能的基础上接入登录、云端存储和公开百科前端。

## 技术说明

- 原生 HTML / CSS / JavaScript
- 无构建步骤
- 无第三方运行依赖
- 数据存储键：`yulengjing_world_wiki_v1`

## 状态

本项目目前处于本地原型与功能整理阶段。
