# 雨棱镜世界观百科（前端 Demo）

这是一个不连接后端的独立前端原型，所有内容均为临时示例数据。

## 运行

需要 Node.js 22.13 或更高版本：

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可。生产构建使用 `pnpm build`。

## 文件结构

- `app/page.tsx`：页面视图与前端交互
- `app/demo-data.ts`：集中封装的 Demo 数据，未来在这里替换真实 API
- `app/globals.css`：视觉样式与响应式规则
- `app/layout.tsx`：站点标题、描述与页面外壳

当前包含百科首页、普通词条、关系网、时间轴，并保留了地图预览入口。

## 从编辑器导入资料

1. 在世界观编辑器点击“导出百科数据”，得到 JSON 文件。
2. 启动百科前端后访问 `http://localhost:3000/?manage=1`。
3. 在右下角“百科数据管理”中选择刚导出的 JSON。
4. 校验成功后页面会刷新，并在当前浏览器中保存这份数据。

普通访客地址不带 `?manage=1`，因此不会看到导入工具。完整备份 JSON 与百科数据 JSON 用途不同，请勿混用。

## 发布给访客

编辑器导出的文件名是 `wiki-data.json`。正式上传网站前，把它放进百科前端的 `public` 文件夹：

```text
百科前端/
└── public/
    └── wiki-data.json
```

网站启动时会自动读取这个文件，因此所有访客看到的是同一份公开资料。`?manage=1` 导入适合本机检查和预览；放入 `public/wiki-data.json` 才是正式发布数据。
