# 雨棱镜首页视觉与动效统一设计

## 目标

将首页五个满屏板块统一为“编辑档案 × 克制玻璃”的视觉体系，在保留现有内容、主色、宋体大标题和核心视觉隐喻的前提下，解决毛玻璃遮字、展览架子穿过图片、板块风格割裂和循环动效过多的问题。

本次只修改主页面。百科词条、关系网、时间轴、展览内部页面和管理后台不在范围内。

## 设计原则

1. 每一屏只保留一个主要视觉隐喻：首页为光谱，百科为档案，展览为 CD 架，多媒体为唱片，更多为目录。
2. 毛玻璃是悬浮功能层，不是背景装饰。只用于顶部导航和极少量浮动操作，不在正文后方铺设大面积模糊层。
3. 维持深蓝、浅蓝、灰白的低饱和配色，继续使用宋体大标题与无衬线小字的组合。
4. 所有主要内容必须在常见电脑端单个视口内完整呈现。
5. 动效必须说明层级、反馈或空间关系；纯装饰的持续运动要克制。

## 全局框架

### 顶部导航

- 保留居中的胶囊导航、左侧 Rainy Prism 标志与右侧页码。
- 毛玻璃只存在于胶囊内部：半透明深蓝底、18px 以内背景模糊、轻微高光边与低对比阴影。
- 删除导航下方覆盖正文的固定模糊带与渐变雾层。
- 深色与浅色板块切换时，只变更导航文字、描边和底色，不改变尺寸和位置。
- 导航链接按下时使用 `scale(.97)`，100–160ms；悬停只改变底色和文字颜色。

### 排版与间距

- 所有板块继续保持一个视口高度与纵向滚动吸附。
- 小型英文编号始终位于标题区域内，顶部留出固定导航的安全距离。
- 大标题使用一致的紧凑行高和负字距；说明文字维持较宽松行高。
- 左右分栏板块使用同一套横向边距与列间距，建立跨板块对齐线。

## 各板块设计

### 01 首页

- 保留光谱和柔和色带，但减少同时运行的动画层数。
- 背景只保留一组 24–32 秒的缓慢折射漂移；鼠标影响降低，避免背景追随感过强。
- 标题与副文案保持平面排版，不套玻璃容器。
- “向下探索”保持轻量圆形提示，按下与悬停反馈使用全局动效参数。

### 02 百科

- 保留左侧标题、原说明文案和“进入百科”。
- 右侧删除持续旋转圆环和透视网格。
- 新视觉改为四张半透明档案卡片，对应“人物、组织、区域、事件”。卡片以轻微错位和前后层级构成一个资料索引，使用细线、编号和低透明度文字，而非大型玻璃面板。
- 卡片在板块进入视口时以 40–60ms 错峰、轻微位移和淡入完成一次入场；入场后保持静止。
- 整组档案视觉可点击进入百科，键盘焦点清晰。

### 03 展览

- 正式采用左文右图布局，比例约为 32% / 68%。
- 左栏依次放置 `02｜EXHIBITION`、标题“展览”、原英文文案和“查看全部”。
- 右栏完整展示 3×2 六张 CD 盒，并继续读取现有首页精选作品配置。
- 架子只覆盖右侧图片区宽度。
- 中间架子定位在上排 CD 的底部，向上轻微覆盖 2–4px，用来形成承托关系；其层级低于 CD，不得穿过封面内容。
- 底部架子使用同样结构贴住下排 CD 底部。
- CD 保留脊背、外框和封面；悬停仅抬升 4–6px、亮度略增，不旋转、不放大到挤压相邻内容。

### 04 多媒体

- 保留唱片作为核心视觉，不修改唱片的基本构造。
- 统一唱片阴影、标题区间距和链接反馈，使其与新的百科档案卡、展览 CD 使用同一套描边与阴影层级。
- 唱片可继续匀速旋转，但速度降低至约 32 秒一周；用户选择减少动态时停止旋转。
- 多媒体列表悬停使用轻微横向位移和背景明度变化，不动画 padding 或其他会触发布局的属性。

### 05 更多

- 保留目录式列表和原文案。
- 将当前通过 padding 变化实现的悬停改为 `transform` 与伪元素淡入，避免布局抖动。
- 列表线条、编号和箭头使用与百科档案卡一致的线宽及透明度。

## 动效系统

### 全局参数

- UI 强缓出：`cubic-bezier(.23, 1, .32, 1)`。
- 屏内移动：`cubic-bezier(.77, 0, .175, 1)`。
- 按下反馈：100–160ms，`scale(.97)`。
- 悬停反馈：160–220ms，只动画 `transform`、`opacity`、`color`、`background-color`、`box-shadow`。
- 板块入场：420–560ms；组内错峰 40–60ms，不阻塞点击。

### 可访问性

- `prefers-reduced-motion: reduce` 时停止背景漂移、唱片旋转和位置型入场，只保留短淡入与颜色反馈。
- `prefers-reduced-transparency: reduce` 时导航改为接近不透明的深蓝或浅色底，并关闭背景模糊。
- 所有链接保留可见焦点样式；悬停动效仅在精确指针设备启用。

## 文件与数据边界

- 正式修改集中在 `site/index.html`、`site/styles.css` 和 `site/script.js`。
- 删除 `prototypes/exhibition-split-preview.html` 及其专用测试。
- 保留首页六张图片的现有数据来源和角色跳转逻辑，不改变 `site/exhibition/exhibition-data.json` 的结构。
- 同步相同的正式页面文件到硬盘上的本地首页运行目录。

## 验收标准

1. 在电脑端常见的 1280×720、1440×900 和 1920×1080 视口中，每个板块均能完整落在单屏内。
2. 展览中六张 CD 完整显示；中间架子只承托上排图片，不穿过任何封面。
3. `02｜EXHIBITION` 等英文编号不被导航或模糊层遮挡。
4. 百科右侧不再出现旋转圆环，替换为静止状态明确的档案卡视觉。
5. 导航以外不存在大面积毛玻璃正文容器。
6. 现有导航、百科入口、展览角色跳转和其他首页链接继续工作。
7. 减少动态与减少透明度系统偏好均有有效降级。
8. 自动布局检查、JavaScript 语法检查和三个电脑端尺寸的浏览器实测全部通过。
